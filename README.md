# Observador Político (PT)

Desenvolvimento de ferramenta de web scraping para coleta e estruturação de dados de políticos e órgãos públicos, com foco na identificação de gargalos de gestão, suporte ao levantamento de hipóteses e geração de insights orientados a dados.

# Observador Político (ES)

Desarrollo de una herramienta de web scraping para la recolección y estructuración de datos sobre políticos y organismos públicos, con enfoque en la identificación de cuellos de botella en la gestión, apoyo al planteamiento de hipótesis y generación de información estratégica basada en datos.

# Political Observer (EN)

Development of a web scraping tool to collect and structure data from politicians and public bodies, focused on identifying management bottlenecks, supporting hypothesis formulation, and generating data-driven insights.
